# 会话筛选与本地导出开发计划

日期：2026-10-21。用户授权：先落地计划，再实现、验证、本机重部署及远程提交推送；远程范围包含 LocalAiMux 当前全部未提交改动，目标 origin/codex/dev，不发布 Release。

## 验收条件

会话记录可组合来源、状态、型号、会话ID、开始时间段与是否含录制正文筛选；列表和导出共用过滤语义。导出覆盖全部匹配记录而非当前50条分页，JSON/MD/XLSX/CSV/TXT/HTML六种格式可经原生保存对话框保存本地，取消不写文件，失败不破坏已有文件。完整保留已保存的消息顺序、Unicode/换行、回答、部分/停止/录制中状态和未知元数据；未录正文明确缺失，不补造历史或调用Provider。

## 实施步骤

1. 存储：CallFilter增加started_from（包含）、started_before（不包含）Unix秒及recorded_only；校验合法时间段，列表和快照导出共用WHERE。单一读取事务取得记录与正文一致快照，导出不使用分页游标；最多10000条/64MiB源数据，超限明确要求缩小范围，不静默截断。无需Schema迁移。
2. 格式：JSON带schema_version/导出时间/过滤条件/记录及正文；MD/TXT适合阅读；HTML自包含、转义全部内容、无脚本与外部资源；CSV一行一调用（消息为JSON列），转义引号/换行并防表格公式注入。XLSX使用摘要、对话内容、导出说明三表；正文按UTF-16安全长度拆分为连续片段并带调用/消息/片段序号，文本固定字符串类型、防公式注入、保留未知为空，不放凭据或Key归属ID。
3. 桌面：原生保存窗口只接受本地路径，文件扩展名与格式一致；后台生成，同目录临时文件+完成后替换、Unix新文件0600；正文不经IPC传给浏览器，不写日志，重复导出互斥。返回导出条数/正文条数/路径或取消。界面显示导出范围与格式、正在导出/取消/成功/失败，期间禁改筛选，时间输入本地时区、含起点不含终点，空值表示不限。
4. 自动验证：时间边界/单边/非法范围、所有组合过滤、跨分页、录制缺失与状态、一致快照/资源上限；六格式解析/长Unicode文本重组/HTML转义/CSV公式防护/XLSX可打开及文本无截断；取消/写入失败/覆盖保护；前端日期转换与筛选一致性。
5. 交互验证：合成IPC在960×680/760×560/800×600、中英与浅深验证查询/导出状态/无溢出/无控制台错误；安装版验证时间控件与原生保存/取消，实际导出在用户本机临时验收目录留证，不上传正文。
6. 交付：更新UX/会话模型/数据库说明、CHANGELOG与HANDOFF；全仓verify与Clippy，按需要SDK兼容烟测。任务0、DB一致备份/完整性通过后执行deploy-local-macos.sh；恢复原API状态，核对进程/安装哈希/旧记录及设置。检查全部diff与敏感数据，再提交并推送origin/codex/dev、确认远端SHA。

## 边界

导出文件包含用户已录正文，保存前明确提示；不读取第三方私有会话，不自动开录制，不改变store:false，不自动真实调用/重跑/清理历史。运行中记录导出的是读取快照，不宣称已完成。Windows/ARM64原生与真实Provider生成不由本轮离线验证替代。PDF/DOCX暂不纳入这六种格式，避免引入独立排版/打印依赖。
