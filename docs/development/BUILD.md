# Build

Install Rust 1.98.1, Node.js 22+, pnpm 11.19.0 and Tauri 2 system prerequisites. Run `pnpm install`, `pnpm dev`, `bash scripts/verify.sh`, or `pnpm tauri build`. The desktop starts its loopback API only when requested; `bash scripts/deploy-local-macos.sh` builds the current working tree, installs to `~/Applications/LocalAiMux.app`, retires the previous `LocalMux.app`, restarts it, and records provenance in `dist/localmux/build-info.txt`. The bundle identifier and existing `~/Library/Application Support/LocalMux` data directory remain stable, so saved connections are retained. This development build retains its default local API key across restarts and deployments: Unix uses an owner-only local credential directory/file (0700/0600), while Windows uses the OS credential store (native acceptance pending). Only the one-time upgrade from the old memory key or explicit replacement rotates it; permissions are saved independently. MiMo credentials remain process-only. See [security TODO](../architecture/SECURITY.md). Check active tasks before deployment. Windows native installation is outside the current Mac-focused acceptance scope.

The macOS shell uses public `NSGlassEffectView`/`WKWebView.underPageBackgroundColor` when the class is available (macOS 26+), without private API flags; earlier systems retain the CSS/opaque fallback. System accessibility preferences are read on the main thread. The current LocalAiMux icon has a deterministic SVG source; software icons are original installed application/CLI assets with hashes in `docs/product/design/liquid-glass-chat/icon-sources.json`. Earlier generated illustrations remain historical only. Tauri CLI exports ICNS/ICO/PNG; the WebView uses a 128px asset for its small brand mark. Frontend state tests currently use Node's native TypeScript loading (Node 22.18+ or 24 recommended). Browser fixture QA does not replace native IPC/live-provider acceptance.
