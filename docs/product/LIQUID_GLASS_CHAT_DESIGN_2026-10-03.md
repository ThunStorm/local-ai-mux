# LocalAiMux 液态玻璃与试对话设计

状态：2026-10-03 设计提案；2026-10-04 已按用户要求进入生产实施，实况见 [实施记录](LIQUID_GLASS_IMPLEMENTATION_2026-10-04.md)。以下保留设计阶段合同。当前阶段交付视觉概念、可交互设计原型、能力边界、实施顺序和验收协议；原型不连接 API。后续实现继续在现有 Tauri 2 / React / Rust 项目中进行，不创建另一套应用。当前实施事实仍以 [HANDOFF](../HANDOFF.md) 为准。

**本阶段验收条件：** 官方原则有来源、全局页面与试对话主要状态有设计、每个参数有真实能力边界、原型可操作且不发出模型请求、验收表区分设计验证与待开发/待真实验证，并保存证据。

## 1. 官方依据与实现边界

2026-10-03 查阅 Apple 官方资料，设计引用而非宣称 Apple 认证。下表中的像素、色值、阈值均为 LocalAiMux 的实现约定，不是 Apple 官方指定值。

| 官方原则 | 本项目决策 | 来源 |
|---|---|---|
| Liquid Glass 建立导航/控制层；内容层用标准材料，效果克制 | 玻璃只用于浮动侧栏、模型控制组、工具栏及浮动操作容器；消息正文、代码、应用列表和参数字段为稳定内容表面，不叠玻璃卡片 | [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) |
| 侧栏浮于内容，空间不足可收起，层级不超过两层 | 主导航总览→应用与连接→试对话→API；高级保留路由/会话；侧栏可手动收起，窄窗口自动收为图标栏，所有入口保留名称提示 | [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars) |
| 工具按用途分组，保持内容优先 | 模型/对话模式/参数开关在同一控制组；新对话在页首，发送/停止固定在编辑器附近；不重复堆砌玻璃按钮 | [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) |
| 外观适应透明度、对比度与减少动效偏好 | 系统/浅/深外观，系统减少透明度与增强对比度的原生桥接、应用内减少透明度开关、无模糊回退；动效遵守减少动态效果 | [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) |
| 原生材质由平台框架提供 | macOS 原生实现使用公开 AppKit 能力需先技术验证；WebView CSS 半透明/模糊只能叫“HIG 对齐的玻璃视觉实现”，不能叫原生 Liquid Glass | [NSGlassEffectView](https://developer.apple.com/documentation/appkit/nsglasseffectview) |

**必须先完成的材质技术验证：** 检查 macOS/SDK 版本、Tauri 原生视图层与 WKWebView 的合成方式，证明公开 `NSGlassEffectView` 的层级、点击命中、窗口缩放、系统外观/辅助功能响应和回退。仅 CSS `backdrop-filter` 不具备系统材质的完整动态光学行为。保留 Tauri 2，不改写 SwiftUI 应用、不使用私有 API、不为视觉效果放宽 CSP。不支持原生材质的系统和 Windows 使用同一布局与不透明回退，并在验收中分别记结果。若只能提供 CSS 版本，需明确保留“原生 Liquid Glass 未验收”这一差异，由用户决定是否接受；不能通过改称效果来宣布原始目标全部完成。

## 3. 全局视觉与页面范围

### 布局与令牌

- 原生系统标题栏/交通灯保留；概念和原型中的标题框只用于窗口示意，产品 WebView 不绘制交通灯。默认 960×680、最小 760×560；另验收 800×600 与 1120×760；不承诺手机 UI。
- 内容底为中性冷灰白/深石墨，玻璃为近乎无色的 regular 风格视觉参考，不用彩色壁纸、渐变光团、装饰性折射动画或 clear 材质承载低对比文字。背景继续铺在侧栏下，侧栏四周有 10–12 px 留白。
- 侧栏展开 184 px、收起 60 px，圆角 20 px；模型控制组圆角 18 px；内容表面圆角 10–14 px；字段 8 px。玻璃限一层，细高光与轻阴影表达边界。
- 系统字体 `-apple-system, BlinkMacSystemFont, system-ui`；标题 22/28，区标题 15/22，正文与控制 13/20，说明 12/18；模型 ID/代码等宽；基础间距 4，模块 16，区段 24 px。
- 浅色内容 `#FAFBFD`、正文 `#18202D`、次文字 `#5F6876`、分隔 `#D7DDE5`、强调 `#0068DB`；深色内容 `#191D25`、正文 `#F1F3F7`、次文字 `#AEB6C4`、分隔 `#3E4655`、强调 `#78B5FF`。数值是项目起点，按实际合成后对比度调整；普通文字目标 ≥4.5:1，控制边界/焦点目标 ≥3:1。
- 按钮/输入 32–36 px，导航 38 px；中文默认，现有英文可切换。焦点环 2 px、图标采用既有 SVG 线性体系；不冒充系统 SF Symbols 或引入位图图标库。
- 120–180 ms 状态反馈；不做循环漂移/液体晃动；`prefers-reduced-motion` 下停用非必要动效；减少透明度/高对比度/不支持模糊时提供不透明表面。

### 各页面

| 页面 | 重构设计与交互 | 保留边界 |
|---|---|---|
| 总览 | 紧凑状态条、开放连接列表、按真实状态给出下一步；进入 API 或试对话 | 不虚构“已验证”、消耗或节省金额；已保存连接≠可调用 |
| 应用与连接 | 玻璃搜索/筛选工具组；平面列表，诊断行内展开；连接与模型验证分别操作 | 产品身份、独立登录、登记/连接区别、额度窗口不合并；不添加未实现 Adapter |
| 试对话 | 模型控制组→消息区→固定编辑器；参数作为右侧检查器，窄屏为覆盖抽屉 | 仅当前 Key 可见真实型号；单轮/多轮按能力启用；无自动真实请求 |
| API | 状态/启停→地址/Key→型号→配置示例的现有顺序；开放配置行、代码用不透明底 | 显示/复制凭据必须点击；授权只读 Agent 的操作仍在 API 权限区 |
| 路由/会话 | 统一字体、表面、焦点与列表密度，保留高级入口 | 本轮不改变 Router、Responses 黏性路由或历史会话语义；会话页不展示提示词/回答 |
| 偏好 | 语言、外观、减少透明度；窄窗口菜单完整可见 | 不因试对话自动开启登录自启或关闭到托盘 |

## 4. 试对话功能边界

**首期包含：** 文本输入、按授权目录切换真实模型、单轮/多轮能力提示、可选系统提示词、按能力调节采样温度/输出上限/Top P、流式开关、发送、停止、复制答案、清空/新对话、请求预览与结果状态。输入与回答仅保留本次进程内存；页面导航保留草稿/消息，退出应用清除。

**首期不包含：** 自动连接/登录/授权、读取第三方私有登录态、自动模型回退、并发对比、历史持久化/云同步、工具调用、文件/图片/语音、富 HTML/远程资源、Markdown 插件执行、自动重试、账单估算、在 CLI 上伪造 Chat 多轮。需后续独立需求才扩展这些项。

### 模型与上下文

- 目录只来自当前 Key 授权后的 `/v1/models`；试对话不放入 `free/cheap/balanced/best` 虚拟路由，不根据模型名称猜能力，不把费用未知标免费。模型失效/断开时保留草稿与旧消息，禁用发送并提供刷新/去连接页动作。
- 若 Key 无 Agent 权限，显示原因和“前往 API 权限设置”，不得直接扩权或轮换 Key。授权完成后由用户刷新目录。
- 单轮模式每次只发当前 `user` 文本；旧结果可留在可视化记录中，每次请求显式标“未携带历史”。系统提示词禁用。多轮模式严格保留 `system/user/assistant` 顺序，只有成功完成的回答进入下轮历史。
- 切换模型或单轮/多轮模式时开启独立上下文；旧消息保留为只读段并标记原模型/参数快照，不跨 Provider 自动带历史。草稿可保留；请求运行时模型、模式、参数、新对话锁定，停止按钮仍可达。参数变化只影响下次请求，不改旧记录。
- 新对话有内容时在编辑器附近确认一次清除，不静默清草稿；清除仅限内存记录。刷新目录不自动发送。

### 参数合同

| 控制 | 首期合同 | 无能力时 |
|---|---|---|
| 系统提示词 | 多轮且明确支持 `system` 角色时可选，不自动附加隐藏提示 | 单轮/未知禁用并说明；不改成 user 文本 |
| Temperature | 默认不覆写；显式启用后控件 0–2、步进 .1；实际合法范围取模型公开能力与网关范围交集 | 禁用；不提交字段、不静默删除已提交值 |
| 最大输出长度 | 默认不覆写；显式启用正整数；有公开上限才给范围，无上限证据时保持未知禁用；字段映射在能力中明确 `max_tokens` /其他已验证字段 | 禁用；不硬编码“所有模型 2048” |
| Top P | 默认不覆写；明确支持后 0–1、步进 .05；首期温度/Top P 互斥覆盖，启用其中一个时另一项恢复模型默认 | 尚未实现或未知禁用，并标原因 |
| 流式输出 | 已声明支持才可开启；首期默认开启，但不支持时明确显示非流式 | 不自动伪装逐字生成；显示等待状态 |
| 恢复默认 | 清空参数覆盖，恢复可支持的流式选择；保留系统提示词（另有清空操作） | 不发起请求 |

能力需描述 `chat_history/system/stream/temperature/top_p/output_limit` 的 SUPPORTED / UNSUPPORTED / UNKNOWN、公开依据及验证状态；模型范围/字段映射必须由 Adapter 描述，经 Gateway 过滤授权后供 UI 使用，不在 UI 写 Provider 分支。已公开但未真实验收的能力可以进入离线开发验证，真实结果不能标为通过。每个发送记录固定模型、模式、被提交参数、端点、耗时、完成/停止/失败；耗时是本机测量，上游未报告 token/费用为未知。当前 Gateway 的零占位 usage 不能作为真实用量。

### 请求与安全

`React 试对话 → Tauri IPC（请求 ID、模型、消息、参数）→ Rust 校验并取进程内 Key → 固定 http://127.0.0.1:8317/v1/chat/completions → 现有 Gateway 授权/限流/路由 → Adapter 官方接口`。所有试对话走 Gateway，不旁路 `verify_model` 的直接 Adapter 路径。固定目标、`no_proxy`、禁重定向；UI 不可传 URL/凭据/请求头；CSP 不放宽。单窗最多一条在途请求。

消息/系统提示词/答案不写 SQLite、localStorage、文件、日志或错误原文；参数偏好首期也不持久化。前端只有非敏感外观偏好可持久化。请求预览隐藏 Authorization，不默认展示完整敏感正文到诊断/遥测；屏幕内预览按用户操作展开，复制仅用户点击。回答按纯文本渲染，代码可复制，不使用 `dangerouslySetInnerHTML`。

发送前做长度、角色、参数和模型校验，沿用 Gateway 1 MiB 请求体上限；UTF-8 按序列化字节计；不为了达到上限静默截断历史。错误使用既有脱敏码并给中文解释。`LMX_UNSUPPORTED_PARAMETER` 属显式能力拒绝，新增 Adapter 错误映射；401/403 提示服务/权限，429 保留原文草稿并建议稍后手动重试；400/超时不自动重试、不切模型、不转付费路由。

### 状态与停止

`未就绪 → 就绪 → 校验 → 等待首块 → 流式接收/等待非流式 → 完成`；终态还包括 `失败`、`已停止`、`超时`。每个请求以 UUID 绑定当前窗口/请求及事件序号，切页/停止/新请求后忽略迟到事件。流解析处理 UTF-8 分片、CRLF、多行/不完整 SSE、上游错误及缺少 `[DONE]` 的异常断开，不能将部分文本当完成。

停止先锁定本地请求终态，再取消 Rust HTTP/SSE 任务、释放活跃任务计数。保留部分回答并标“已停止”，不自动进入多轮历史。HTTP 连接取消不能保证远端推理立即停止或停止计费，界面说明“已停止本机接收，上游可能继续执行”；CLI 子进程终止/资源回收需单独测试。系统关闭/部署时先等活跃请求结束，不能强制退出。
