# Product spec

The current user path is installed app discovery → explicit official runtime connection → actual reported models and quota → local OpenAI-compatible text API configuration. Detection and registration do not prove login or model invocation. The [product alignment plan](../LOCALMUX_PRODUCT_ALIGNMENT_PLAN_2026-09-28.md) defines the incremental acceptance target; [supported apps](SUPPORTED_APPS.md) and [handoff](../HANDOFF.md) distinguish implemented code from live validation.
