# 桌面交互

macOS 界面按 [macOS 视觉规范](MACOS_VISUAL_SPEC.md) 实现：保留原生窗口标题栏，WebView 内使用固定侧边导航、紧凑页标题和内容区独立滚动。应用以可搜索/按状态筛选的列表行展示，详情在行内展开；API 的地址、Key、模型和配置示例按操作顺序排列，旧路由与会话入口保留在高级分组。
总览展示实际发现数、已保存连接、API 运行状态、连接概览和下一步；切换页面回到页首。偏好设置在侧边栏底部展开，窄窗口的菜单向上打开以保留原生选择器空间。

首启显示欢迎、扫描、连接、开启 API 的路径并自动做只读扫描。Discover 页展示检测结果、版本、路径、诊断和重扫；已实现的官方 CLI 可点击「添加」并走真实连接验证，完整的桌面应用可点击「添加应用」登记安装记录。登记后的状态明确显示「已添加应用（仅登记）」，不冒充已连接，也不读取桌面登录凭据。API 页可显式启停 Gateway、创建并一次性查看/复制 Key、撤销刚创建的 Key。

当前主导航以总览、应用与连接、API 为先；原路由和会话页移入「高级」入口，保留旧配置。发现页按应用 ID 合并桌面应用与官方 CLI 候选，优先显示包内 CLI，其他可扫描到的运行时可切换；保存的连接与已完成真实推理不混为一谈。API 页首屏提供本机 Key 状态、显式显示/复制、重建撤销、从当前授权 `/v1/models` 读取的实际模型 ID，以及 Base URL、模型 ID、Endpoint、JSON/cURL/Python/TypeScript 配置复制。示例默认隐藏 Key，用户点击复制完整配置时才读取 OS 凭据。首次启动 API 创建最小权限 Key；要使用只读 Agent，用户须明确勾选并重建 Key。只有用户点击「测试此模型」才发送可能消耗额度的短请求；成功后仅在当前界面会话标为已验证。没有模型或服务未启动时给出相应提示，不显示合成模型。

MiMo API 提供单独的显式 Key 输入；输入验证后 Key 仅写系统凭据库，SQLite 只记固定引用。MiMo 桌面登录与开放平台 API Key 分开。Qoder 桌面应用只有安装时，界面提供官方 CLI 安装说明。

Routing 页显示 free/cheap/balanced/best 的当前目标或“暂无符合条件的模型”；Reserve 进入 free、balanced 使用计费模型都需用户单独勾选并保存。best 需要 exact model ID，balanced 需要显式优先级。官方额度没有上游报告时显示“未知”。

应用行按连接展示已报告额度窗口；Codex 主/次窗口分别显示百分比，展开后可看各自重置时间，不合并成余额。没有官方报告为未知，旧观测超过 10 分钟标过期。此处不以额度可用推断模型已通过真实调用。

Sessions 页展示已完成 Responses 调用产生的 Conversation ID、实际模型、供应商、最近活动时间及是否可续接；可查看路由事件，不展示提示词/回答正文。当前没有活跃 Run 取消控件，待 Phase 8 进程与 Run 管理补齐。界面默认中文，支持英文及系统/浅色/深色外观。
