试对话仅使用当前 Key 授权的真实目录型号。发送经 Rust IPC→固定本机 Gateway，Key 不进入前端；只有点击发送/⌘Enter 才推理。CLI 目前单轮，HTTP 按能力支持多轮；切换型号/模式开启独立上下文，旧消息留为只读段，不自动跨模型携带历史。参数只有明确报告支持才启用，默认不覆写，温度/Top P 覆写互斥；恢复默认不发请求。运行时模型/参数/新对话锁定，发送位置变停止，窄屏面板避开编辑器。失败保留草稿，不自动重试/换模型；停止只保证本机接收取消，上游可能继续执行。成功完整回答才进入下轮历史；正文、请求预览和回答只保留本次运行内存，切页保留、退出清除，默认不写 SQLite；显式开启下述录制时保存正文副本，不写 localStorage/日志。用户复制除外。所有回答纯文本显示。

应用页只显示当前已有可实现 Bridge 的应用：Codex、Qoder、Qoder CN、MiMo Code，以及实际扫描到独立 CLI 时的 CodeBuddy Code。WorkBuddy、CodeBuddy CN、TRAE、Ollama 等没有当前可用 Adapter 的项目不进入主列表。每行可「移出列表」；此操作只持久隐藏，可从「已移出列表」恢复，不删除已保存连接或桌面登记。
Codex/Qoder/Qoder CN 通过官方只读状态命令检查登录；只有明确需要凭据时显示对应官方登录入口，登录开始后每 10 秒检查一次、最多约 3 分钟，完成后自动显示已登录。MiMo Code 匿名可用时不要求登录，只有上游确认认证缺失才引导。点击「验证连接」只读目录并保存连接；展开卡片可选择型号，点击「测试此模型（可能消耗额度）」才发送真实短请求。连接错误只在所属页面显示。API 页的 Agent 模型仍遵守当前 Key 授权，显式允许只读 Agent 并保存授权后才进入可调用目录，授权保存不轮换 Key。

当前主导航以总览、应用与连接、试对话、API 为先；原路由和会话页移入「高级」入口，保留旧配置。发现页按应用 ID 合并桌面应用与官方 CLI 候选，优先显示包内 CLI，其他可扫描到的运行时可切换；保存的连接与已完成真实推理不混为一谈。API 页首屏提供本机 Key 状态、显式显示/复制、重建撤销、从当前授权 `/v1/models` 读取的实际模型 ID，以及 Base URL、模型 ID、Endpoint、JSON/cURL/Python/TypeScript 配置复制。示例默认隐藏 Key，用户点击复制完整配置时才读取默认 Key 凭据。研发版默认 Key 与已经保存的权限跨重启/部署保留；旧内存模式首次升级可换一次。要使用只读 Agent，用户明确勾选并保存授权，Key 不变；重建/撤销是独立的主动操作。凭据异常显示恢复提示，不自动换 Key。只有用户点击「测试此模型」才发送可能消耗额度的短请求；成功后仅在当前界面会话标为已验证。没有模型或服务未启动时给出相应提示，不显示合成模型。

MiMo API 提供单独的显式 Key 输入；输入验证后，研发版 Key 仅保留在内存中，重启后需重新连接。MiMo 桌面登录与开放平台 API Key 分开。Qoder 桌面应用只有安装时，界面提供官方 CLI 安装说明。
