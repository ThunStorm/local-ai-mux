# Brief

LocalMux / 智汇枢 is a macOS and Windows Tauri desktop app that will expose explicitly connected local AI runtimes through a loopback OpenAI-compatible API. It is for one user's own installed agents and subscriptions. It is not a SaaS, public relay, provider credential scraper, or GUI automation bridge. Phase 0 is repository foundation only. Source of scope: `LOCALMUX_PROJECT_PLAN.md`.
