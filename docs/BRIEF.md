# Brief

LocalMux / 智汇枢 is a Tauri desktop app that exposes explicitly connected local AI runtimes through a loopback OpenAI-compatible text API. It is for one user's own installed agents and subscriptions. It is not a SaaS, public relay, provider credential scraper, or GUI automation bridge. Phase 0–8 code exists; the current Mac-focused incremental scope is in `docs/LOCALMUX_PRODUCT_ALIGNMENT_PLAN_2026-09-28.md`, with verified status in `docs/HANDOFF.md`. Windows native acceptance is deferred.
