# LocalAiMux v0.3.1

Responses 在获取 Agent 执行权后复核父响应，成功映射与调用终态同事务提交。流式启动超时与 Chat 使用相同的连接冷却，拒绝切换型号的审计事件过滤无效型号。正文录制对无匹配的脱敏规则复用文本，保留逐块持久化和跨块脱敏。

沿用 Schema 13。本次封版包为 macOS Apple Silicon 预发布，使用既有本机 Key 和数据目录。发布渠道及签名状态见[发布说明](../development/RELEASE.md)。

录制性能专项使用 912 个普通文本分片共 1,050,624 字节。在同机优化构建中，脱敏返回值累计拥有的文本从 479,609,856 字节降至 0，单次测量为 134 ms 和 101 ms。该测量仅覆盖脱敏函数，SQLite 仍逐片写入累计快照。

本机 macOS 验收通过 158 项 Rust 测试、12 项前端测试、Clippy 严格检查及 Python/TypeScript SDK 各 25 项隔离测试。两项需要显式指定官方 CLI 路径的检查跳过。未调用真实 Provider。原生打包使用 arm64。
