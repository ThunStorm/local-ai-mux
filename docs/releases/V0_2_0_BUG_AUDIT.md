# LocalAiMux v0.2.0 隐性问题检查

日期：2026-10-26。范围覆盖限时、异步设置、Gateway流/非流、HTTP/CLI边界、正文存储、导出、权限/续接与升级兼容。检查采用源码审阅、虚拟时钟、回环合成服务与文件读回，不发真实模型请求。结果不代表全平台或所有厂商均无缺陷。

## 已修复并复现验证

### BUG-01：保存结果未知时仍显示旧配置已保存

原界面仅显示错误，保留旧saved值；如果IPC在后台写入成功后传输失败，旧值与实际配置不同。初始读取也未作为忙状态保护，可能与重新读取竞争。

修复：初载即进入忙状态；读取/保存采用请求代次保护、卸载失效；任何未确认结果将saved设为未知、禁改输入与保存，只有重新读取成功后恢复。合成IPC模拟“已写入但返回失败”，确认不再误显示旧值，重新读取取得实际新值；1200保存/重载、1201拒绝及中英浅深三尺寸通过。

### BUG-02：HTTP非流式输出可绕过大小边界

原HTTP Adapter直接response.json，无有界读取；非流式Gateway也未像流式一样检查8MiB文字上限，超大结果可能先分配/解析大量内存或被当作成功返回。

修复：模型目录/公开本机元数据JSON最多4MiB，非流式响应JSON最多64MiB，在Content-Length与chunk复制前检查；正文8MiB上限由HTTP Adapter和Gateway Chat/Responses两层核对。SSE缓冲同样在扩容前检查。超限统一LMX_OUTPUT_TOO_LARGE，失败不保存超大正文、不新建成功续接映射，也不根据该错误推断供应商停服。回环声明长度/无声明chunked超限、正常小JSON、HTTP非流大文本和两端点自定义Adapter大结果均有回归。
