# LocalAiMux v0.3.0

macOS Apple Silicon 预发布。GitHub 提供 `LocalAiMux-macos-arm64.zip` 和源码归档，应用包尚未通过 Developer ID 签名及公证。变更明细见 [CHANGELOG](../../CHANGELOG.md)。

- 偏好新增“数据与日志”。可配置业务数据目录，在下次启动迁移一致快照，并管理脱敏日志轮转、保留及占用显示。
- Gateway 对可识别的上游首包超时返回分层诊断。连接冷却返回剩余等待和未发出标记；Qoder CLI 有界 stderr 辅助识别首包超时。
- 新增模块总览、请求生命周期和数据治理文档，整理现行开发与发布说明，移除本机验收产物和过时占位文件。

SQLite Schema 仍为 13，默认数据目录、bundle 标识和本机 Key 锚点沿用，目录变更由用户显式排期。详见[数据治理](../architecture/DATA_LIFECYCLE.md)。

源码可按[构建说明](../development/BUILD.md)构建。正式签名安装包、自动更新、真实上游质量和远端取消各自独立验收。验证入口见[交接](../HANDOFF.md)与[发布流程](../development/RELEASE.md)。
